## PRD — Modal Konfirmasi Logout (Super Admin & Admin/Mentor)

**Latar belakang:** Role user (student) sudah punya modal konfirmasi logout. Super admin dan admin/mentor saat ini logout langsung tanpa konfirmasi dari pill profil sidebar backoffice — salah klik langsung mengakhiri sesi.

**Tujuan:** Modal konfirmasi (judul "Log Out", pesan "Are you sure you want to log out?", tombol Cancel & Log Out) muncul saat super admin / admin-mentor memilih Logout. Aksi tetap memakai endpoint `GET /logout` yang sudah ada — controller tidak diubah.

**Perilaku:**
1. Klik "Logout" di popover pill profil → modal muncul (overlay blur), popover tertutup.
2. Cancel / Escape / klik overlay → modal tertutup, tidak ada logout, fokus kembali.
3. Log Out → redirect ke `/logout` (perilaku existing).
4. Focus trap di dalam modal; Cancel fokus awal (mengikuti pola modal user yang sudah ada).

**Non-goals:** tidak mengubah logout role user, tidak membuat endpoint baru, tidak mengubah modal user.

**Acceptance criteria:**
- Dua komponen baru per role (duplikasi komponen user, konvensi namespace per role): `components/ui/super_admin/modal/logout_confirm/index.hbs` + `components/ui/admin/modal/logout_confirm/index.hbs`.
- Klik Logout di kedua role menampilkan modal; cancel membatalkan; confirm logout berfungsi.
- Nama fungsi global/event unik per role (hindari tabrakan seperti kasus `confirmDelete()` sweetalert yang didokumentasikan di delete_confirm).
- Tidak ada regresi logout role user.

## Implementation Plan

1. **Komponen super admin** — `src/views/partials/components/ui/super_admin/modal/logout_confirm/index.hbs`: duplikat dari `components/ui/user/modal/logout_confirm/index.hbs` dengan nama unik: global `openSuperAdminLogoutModal()`, Alpine `superAdminLogoutConfirmModal()`, event `super-admin-logout-confirm:open`, aria id `super-admin-logout-confirm-modal-*`.
2. **Komponen admin** — `src/views/partials/components/ui/admin/modal/logout_confirm/index.hbs`: sama, dengan `openAdminLogoutModal()`, `adminLogoutConfirmModal()`, event `admin-logout-confirm:open`, aria id `admin-logout-confirm-modal-*`.
3. **Sambungkan di sidebar** — `src/views/partials/sidebar.hbs`: render komponen sesuai role (`super_admin` → komponen super admin, `admin` → komponen admin) di akhir partial, analogi dengan cara `shell_frame` memasang modal user.
4. **Ubah user_pill** — `src/views/partials/components/ui/sidebar/user_pill/index.hbs`: item Logout `<a href="/logout">` diganti `<button>` yang memanggil `openSuperAdminLogoutModal()` / `openAdminLogoutModal()` berdasarkan prop `role` (sudah diterima komponen), sekaligus menutup popover saat modal dibuka. user_pill hanya dipakai sidebar backoffice (admin/super_admin) sehingga tidak memengaruhi role user.
5. **Verifikasi** — build template (`npm run build`), uji alur klik Logout kedua role (cancel & confirm), pastikan logout role user tetap normal.
